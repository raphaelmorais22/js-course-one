# JavaScript Fundamentals - Part 1

## 📚 Sobre este módulo

Este repositório contém meus estudos da seção **JavaScript Fundamentals - Part 1** do curso **The Complete JavaScript Course**, de Jonas Schmedtmann.

Nesta etapa são apresentados os conceitos essenciais da linguagem JavaScript, construindo uma base sólida para o desenvolvimento web moderno.

---

## 🎯 Objetivos de Aprendizagem

Ao concluir esta seção, serei capaz de:

- Entender o papel do JavaScript no desenvolvimento web.
- Escrever e executar códigos JavaScript no navegador.
- Declarar e manipular variáveis.
- Trabalhar com diferentes tipos de dados.
- Utilizar operadores para realizar cálculos e comparações.
- Aplicar lógica booleana em tomadas de decisão.
- Criar estruturas condicionais com `if` e `else`.
- Compreender o conceito de coerção e conversão de tipos.
- Utilizar template literals para criar strings dinâmicas.
- Resolver pequenos desafios utilizando lógica de programação.
